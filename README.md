## ⭐ Featured Projects

### 📝 文章整形ツール

文章の余分な空白・空行・改行などを、ブラウザ上で簡単に整えられるWebツールです。

生成AIから出力された文章を整えるときにも使えるようにしています。

🔗 [文章整形ツールを使ってみる](https://yumin-snoopy.github.io/tools/text_formatter/)

---

### 📊 Excel関数検索ツール

「こんなことをしたい」からExcel関数を探せる、初心者向けの検索ツールです。

関数名だけでなく、使い方・構文・引数・数式例なども確認できます。

🔗 [Excel関数検索ツールを使ってみる](https://yumin-snoopy.github.io/tools/excel_function_search/)

---

### 🖼️ 画像リサイズ・圧縮ツール

画像の横幅・画質・保存形式を指定して、ブラウザ上でリサイズや圧縮ができるツールです。

画像は外部へ送信せず、ブラウザ内で処理します。

🔗 [画像リサイズ・圧縮ツールを使ってみる](https://yumin-snoopy.github.io/tools/image_resizer/)
